# Employee Salary Calculator

## Project Description

This project is a Python-based Employee Salary Calculator.
The program calculates and displays the Gross Salary and Net Salary
along with all individual salary components.

## Objectives

- To calculate Gross Salary
- To calculate Net Salary
- To display individual salary components
- To understand the use of Python for salary calculations

## Technologies Used

- Python
- GitHub

## How to Run

1. Download the Python file.
2. Open it using Python IDLE or VS Code.
3. Run the program.
4. Enter the required values.
5. The program will display the salary details.

## Features

- Calculates allowances
- Calculates Gross Salary
- Calculates deductions
- Calculates Net Salary
- Displays individual components

## Conclusion

The Employee Salary Calculator demonstrates the use of Python
programming to perform salary calculations efficiently.
